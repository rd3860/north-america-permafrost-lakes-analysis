# Analysis Notebooks

This directory contains the two main analytical workflows developed for the North America Permafrost Lakes Analysis project.

## Notebook Structure

1. `01_spatial_distribution_analysis.ipynb`  
   Examines the geographic distribution of North American lakes and reservoirs through lake-type classification, country-level comparison, latitude binning, spatial aggregation, and GeoPandas mapping.

2. `02_timeseries_weather_analysis.ipynb`  
   Examines lake surface-area time series, missing-data patterns, seasonal variation, weather associations, and selected interpolation methods.

The notebooks are presented in analytical order and include explanatory Markdown, Python code, visualizations, and interpretation of results.
